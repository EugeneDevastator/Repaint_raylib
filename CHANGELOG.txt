=== Batch 1 Changelog ===

1. Brush preview now draws entire segment (center to right) with proper spacing, scatter, and size modulation
2. Added tool power slider (bpPower) forwarded to brush_blend shader via uPwr uniform
3. Window icon now uses project icon from QT repo (reicon.ico / ICON16.png)
4. Added two erase modes:
   - Alpha Erase: reduces canvas alpha by brush alpha
   - Color Erase: applies color to semi-transparent regions using gamma-based formula
5. Flipped gradients in vertical sliders (bottom-to-top now matches expected direction)
6. Small brush handling: when rad_out < 1px, stamp size is scaled down proportionally and opacity is reduced
7. Added changelog button in left panel - reads CHANGELOG.txt from app directory
8. Added layer threshold and feather sliders in layer panel:
   - Threshold: cuts off pixels below alpha level (default 0 = disabled)
   - Feather: softness of threshold edge (default 1 = fully soft)
   - Values forwarded to layer_blend shader
