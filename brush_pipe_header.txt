The fix is small and structural.

phaseShift and firstDabSequenceNumber don't belong in PackedSegment. They're builder continuity state, not segment identity.

Restructure like this:
Code Block
PackedSegment {
    SegmentEndpoint A, B;
    vec2 worldCurveA, worldCurveB;
    // NO phaseShift, NO firstDabSequenceNumber
}

SegmentContinuity {
    float phaseShift;         // arc remainder from previous segment
    int nextDabSequenceNumber;
}
ISegmentBuilder becomes:

Code Block
ISegmentBuilder {
    // Pure function — no hidden state dependency
    DabbedSegment BuildSegment(
        PackedSegment seg,
        SegmentContinuity continuity  // explicit, not derived by unpacking
    );
    
    // Returns continuity for next segment — caller owns it
    SegmentContinuity GetContinuity(DabbedSegment built);
    
    bool HasSegmentAnyDabs(PackedSegment seg, SegmentContinuity continuity);
}
IStrokeEngine owns and tracks SegmentContinuity internally per stroke. It's local runtime state, not packed/transmitted.

IStrokeEngine {
    void StartStroke(BrushUserModelPacked, targetQuadId);

    PackedSegment DequeueSegment();  // clean — no continuity embedded

    // SegmentContinuity currentContinuity — updated after each build
